Preset tersimpan

Preset disimpan di IndexedDB perangkat ini (bukan di server). Media ikut disimpan sebagai blob lokal.

Cara kerja & batasan

  • • 100% lokal. Tidak ada server: file .xml dan media tidak pernah meninggalkan perangkat Anda.
  • • Tidak ada eksekusi kode. Berbeda dengan pembaca preset yang memakai new Function untuk skrip efek, studio ini tidak pernah menjalankan JS dari dalam file preset.
  • • Transformasi akurat. Posisi, skala, rotasi, opacity, blend mode, dan keyframe mengikuti formula Alight Motion.
  • • Efek best-effort. Hanya efek yang ada di registri lokal (— efek) yang dirender. Sisanya ditandai jelas di panel Layer, bukan diam-diam dilewati.
  • • Batas ukuran. Maksimal 32 MB per file .xml, diparse di Web Worker agar UI tidak beku.
